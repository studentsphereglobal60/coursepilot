Data Analytics · Beginner guide

Excel, SQL or Python: Where Should You Start?

All three tools are useful for working with data, but they solve different problems. Your best starting point depends on the kind of data work you want to do and your current experience.

Excel: a practical first step

Excel is useful for organising tables, cleaning simple datasets, using formulas, creating charts and building reports. It is approachable for many office and business tasks because you can see the data and results together. Start here if you want to improve everyday reporting, budgeting or spreadsheet work.

SQL: ask questions of databases

SQL is used to retrieve and summarise information stored in relational databases. You use queries to filter rows, combine tables, group results and calculate totals. It is especially useful when working with larger datasets or in roles where information is stored in company databases. You do not need to become an expert programmer before learning basic SQL.

Python: automate and analyse

Python is a general-purpose programming language. For data work, it can automate repetitive tasks, clean files, analyse datasets and create visualisations. It offers flexibility, but you will need to learn programming foundations and practise writing code.

A beginner-friendly learning order

  1. Learn spreadsheet basics and practise with a small dataset.
  2. Learn SQL fundamentals and answer simple questions from sample tables.
  3. Learn Python basics if you want to automate tasks or perform more flexible analysis.
  4. Combine the tools in one small portfolio project, documenting the question, steps and result.

Do you need all three?

No. Start with the tool closest to your immediate goal. An office reporting role may benefit most from Excel. Database-heavy analysis often needs SQL. Automation or more advanced analysis may call for Python. Over time, the tools complement one another.
